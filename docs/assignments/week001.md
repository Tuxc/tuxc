# 1. 创建自己的网页

## 部署环境
- 安装`Chorme`(浏览器)
- 安装`Git`(版本控制&环境工具)
- 安装`Github Desktop`(`Git`的可视化工具)
- 安装`VS code`(代码编辑器)
  
## 部署Github Pages
- 根据[Github Pages]的第二阶段

## 操作记录
- 1. 可以在`GitHub`新建`repository`时，点`Import a repository`，输入`https://github.com/pc-panpan/haitec`，可以和[Github Pages]`Step 4` 中“打开教师提供的模板仓库页面，点击绿色的 Use this template -> Create a new repository”一个效果
- 2. 在`VS code`修改内容后，可以直接在`VS code`中直接提交到`GitHub`上

# 2. Fusion

- 安装、注册、<u>淘宝</u>激活
  
## 作图
- 设计类型有零件、部件、混合
  > 零件：单个实体  
  > 部件：组装零件  
  > 混合：全能实现  
- 以原点为标的作图，对称图形也可以以原点为对称点
- 作草图时，面要选对
- 拉伸时，注意是否要新增实体
- 最好在实体后阵列，减轻计算机负担

# 3. 3D打印

## 工具
- 3D模型简易设计使用[tinkercad]，并且可以导入`Fusion`
- 软件工具`Bambu Studio`

## 打印
- 选择打印机
- 选择耗材
- 选择工艺，可以设置打印出的精细度，精细度和速度负相关
- 强度与实物内部实心结构相关
- 当模型有悬空的部位时，需要选择支撑(树状)
