# 1. 创建自己的网页

- ## 部署环境
  - 安装`Chorme`(浏览器)
  - 安装`Git`(版本控制&环境工具)
  - 安装`Github Desktop`(`Git`的可视化工具)
  - 安装`VS code`(代码编辑器)
  
- ## 部署Github Pages
  - 根据[Github Pages]的第二阶段

- ## 操作记录
  - 1. 可以在`GitHub`新建`repository`时，点`Import a repository`，输入`https://github.com/pc-panpan/haitec`，可以和[Github Pages]`Step 4` 中“打开教师提供的模板仓库页面，点击绿色的 Use this template -> Create a new repository”一个效果
  - 2. 在`VS code`修改内容后，可以直接在`VS code`中直接提交到`GitHub`上
